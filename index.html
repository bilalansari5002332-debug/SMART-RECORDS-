Vendor Folders

Create a folder once for each vendor. Every OUT and IN entry for that vendor stays inside that folder.

🔎 Continue / Find Entry

If you left the work unfinished, search by vendor and/or invoice/challan number and continue from the same record.


📋 Pending Outside Material — Continue From Last Entry

Oldest pending OUT entries are shown first. This makes it easy to check what went outside yesterday or earlier and whether it has come IN.

💰 Clear Received Material After Payment

When you pay a vendor for material already received, select the vendor and clear all received entries together. Nothing is permanently deleted — cleared entries stay in Paid/Cleared History for checking.

💾 Backup & Restore

Your normal backup is a readable file showing the actual vendor records. A separate restore file keeps the exact app data.

📦 Permanent Portable Copy = the HTML itself contains your current data. It does not depend on old browser storage when opened from File Manager.

The restore backup does not change anything until you select a JSON file. The full readable backup can be opened like a normal document.
